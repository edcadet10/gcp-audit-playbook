# Disconfirmation plan

Registered 2026-10-14 before implementation and test execution.

**Claim:** this reusable work program can collect scoped Google Cloud evidence without changing cloud resource configuration, and preserves uncertainty when evidence is incomplete.

**Kill criteria:** any dispatched cloud mutation; collection from a project outside the declared organization; a failed, truncated or unavailable read represented as complete; or an audit step without an executable evidence procedure and Google documentation.

**Cheapest falsifying experiment:** offline adversarial tests of the actual dispatcher and collector using deterministic fake CLI responses. Try a write operation, shell metacharacters, wrong ancestry, identity drift, failed authentication, permission denied, malformed JSON, an empty result, and a reached sampling limit. Inspect all registered command paths and flags against Google references. Reconcile every control and phase against generated scripts and links.

**Evidence boundary:** offline tests cannot demonstrate actual IAM permission sufficiency, endpoint availability, organization-wide completeness, control effectiveness, or compatibility with every CLI version. A future authorized engagement must pilot representative reads and independently reconcile the population. No customer environment is connected while authoring this repository.

**Read-only definition:** cloud configuration and customer data are not modified. Local SDK installation, authentication credential storage, evidence files, and provider access/audit telemetry are expected side effects. Semantic reads can use HTTP POST (for example getIamPolicy); HTTP method alone is not a reliable classifier. Installation and authentication are separate from the cloud collection allowlist.

Sources: [Cloud Asset Inventory consistency and supported types](https://docs.cloud.google.com/asset-inventory/docs/asset-types), [IAM policy inheritance](https://docs.cloud.google.com/iam/docs/resource-hierarchy-access-control), [Cloud Audit Logs](https://docs.cloud.google.com/logging/docs/audit), [CLI authentication](https://docs.cloud.google.com/sdk/docs/authenticate).
